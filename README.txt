SO X - تشغيل الموقع

1) ثبّت Node.js بإصدار 22 أو أحدث.
2) افتح الطرفية داخل هذا المجلد ونفّذ:  node server.js
3) افتح المتصفح على:  http://localhost:3000

للنشر على الإنترنت (Railway أو Render):
- ارفع المجلد كاملاً، واختر Node 22، وأمر التشغيل: node server.js
- أضف متغير بيئة اسمه ADMIN_KEY بقيمة سرية طويلة.
- فعّل قرص تخزين دائم (Volume) للملفين: sox.db ومجلد uploads
  وإلا ستضيع البيانات عند إعادة تشغيل الاستضافة.
- اربط دومين خاص وفعّل HTTPS.

--- ملفات إضافية ---
- لوحة الإدارة: /admin.html (تحتاج ADMIN_KEY) لحذف الكروت والتعليقات ورفع الحظر.
- Dockerfile و render.yaml: نشر تلقائي على Render مع قرص تخزين دائم.
- متغير DATA_DIR: مكان حفظ قاعدة البيانات والصور (الافتراضي: نفس المجلد).
